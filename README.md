# Resto

Resto is a modern restaurant landing page built with HTML and CSS. It showcases a stylish food-themed homepage with sections for about, special dishes, menu highlights, customer testimonials, and reservations.

## Preview

![Resto website preview](resto.png)

## Features

- Attractive restaurant homepage design
- Sections for about, specialties, menu, team, and reservation
- Responsive layout with elegant styling
- Clean visual presentation for a food business website

## How to view the project

1. Open the project folder in your browser.
2. Launch the file named `resto.html`.
3. The website will load directly in your browser.

## Technologies used

- HTML
- CSS
- Font Awesome icons
